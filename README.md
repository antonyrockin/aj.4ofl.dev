# Antony Johny — Portfolio (`aj.4ofl.dev`)

Personal portfolio of Antony Johny — first-year BCA student learning and building for the web.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React & TanStack Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) with custom typography & palettes
- **Animation**: [Motion](https://motion.dev) (declarative scroll-linked animations with reduced-motion support)
- **Tooling**: [Vite](https://vitejs.dev), [TypeScript](https://www.typescriptlang.org)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) (v20+) or [Bun](https://bun.sh) installed.

### Installation

```bash
# Install dependencies
npm install
# or
bun install
```

### Development

```bash
npm run dev
# or
bun dev
```

The app will start locally, typically at `http://localhost:3000` or `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
